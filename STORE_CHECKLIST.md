# Chrome Web Store Publishing Checklist

## Pre-Upload Checklist
- [x] Extension loads without errors
- [x] All required files included in ZIP
- [x] Icons present (16x16, 32x32, 48x48, 128x128)
- [x] Manifest V3 compliant
- [x] Privacy policy created
- [x] Description written
- [ ] Screenshots created
- [ ] Tested on different websites
- [ ] Keyboard shortcut works
- [ ] Popup interface works
- [ ] Options page works

## Store Listing Requirements
- [ ] Extension name: "Tab Alternator"
- [ ] Category: Productivity
- [ ] Language: English (US)
- [ ] Privacy policy uploaded
- [ ] Screenshots uploaded (at least 1, recommended 3-5)
- [ ] Description under 16,000 characters
- [ ] Summary under 132 characters
- [ ] Single purpose declared
- [ ] Permissions justified

## Screenshots Needed
1. **Popup Interface** - Show the main popup with recent tabs
2. **Options Page** - Show the settings and privacy controls
3. **In Action** - Show the extension working (optional)

## Common Rejection Reasons to Avoid
- Missing or unclear privacy policy
- Unjustified permissions
- Poor description or screenshots
- Extension doesn't work as described
- Missing required information
- Violation of Chrome Web Store policies

## Post-Publication
- [ ] Monitor user reviews
- [ ] Respond to feedback
- [ ] Update as needed
- [ ] Track download statistics
