3. Screenshot Checklist

Required Screenshots:

  • ✅ Popup Interface - Main extension popup with recent tabs
  • ✅ Options Page - Settings and privacy controls
  • 🔄 In Action (Optional) - Extension working with multiple tabs

Screenshot Tips:

  • Use high resolution (at least 1280x800)
  • Ensure text is readable
  • Show realistic data (not empty states)
  • Use consistent browser theme
  • Capture full windows, not cropped areas

4. How to Take Screenshots

Step-by-Step Process:
  1. Prepare the extension:
    • Load the extension in Chrome
    • Open several tabs with different websites
    • Use the extension to build up some tab history
  2. Take Popup Screenshot:
    • Click the extension icon to open popup
    • Use browser's screenshot tool or system screenshot
    • Capture the full popup window
  3. Take Options Screenshot:
    • Right-click extension icon → Options
    • Or go to chrome://extensions/ → Tab Alternator → Details → Extension options
    • Capture the full options page
  4. Save and organize:
    • Save as PNG files
    • Name them: popup-screenshot.png, options-screenshot.png
    • Keep them in the tab-alternator folder

5. Browser Screenshot Tools

Recommended Tools:
  • Chrome DevTools: F12 → Device toolbar → Screenshot
  • macOS: Cmd+Shift+4 for area selection
  • Windows: Snipping Tool or Win+Shift+S
  • Linux: Built-in screenshot tools
